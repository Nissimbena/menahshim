# ניחושי הפועל ירושלים

משחק ניחושים דו-ממדי (2D) לאוהדי הפועל ירושלים, בנוי עם TypeScript, Vite ו-Phaser 3.

## הרעיון

לפני כל משחק של הפועל ירושלים, המשתמשים מנחשים:

1. **12 השחקנים** שהמאמן ירשום לסגל המשחק.
2. **החמישייה הפותחת** מתוך אותם 12.
3. **קו סטטיסטי** (נקודות, ריבאונדים, חטיפות, איבודים, חסימות) לכל אחד מ-12 שחקני הסגל שנבחרו.

## טכנולוגיות

- TypeScript + Vite
- Phaser 3 (מסך פתיחה / תפריט)
- HTML/CSS רגיל למסך הניחושים (מתאים יותר לרשימות/טפסים מאשר canvas)

## מבנה

```
src/
  config/GameConfig.ts       # גדלים משותפים, שם המשחק וצבעי המותג
  entities/Basketball.ts     # טקסטורת כדורסל שנוצרת בקוד
  scenes/                    # סצנות Phaser (Boot, Preload, Menu)
  prediction/
    types.ts                 # מודל הנתונים של שחקן/ניחוש
    roster.ts                 # סגל הפועל ירושלים (מ-hapoel.co.il/team)
    PredictionScreen.ts        # תהליך: סגל -> חמישייה פותחת -> סטטיסטיקות -> סיכום
```

## הרצה מקומית

```
npm install
npm run dev
```
